# Typed Messages Implementation Plan

> Execute inline with the executing-plans workflow; preserve the existing TCP ownership and Allman formatting.

**Goal:** Encode, validate, decode, and exchange Heartbeat/ShoppingCart messages with a CRC-32 integrity check.

**Architecture:** A separate codec maps domain structures to DataBuffer. Boost.CRC validates header and payload; the existing transport carries the complete encoded buffer unchanged.

**Tech stack:** MSVC latest C++, CMake/vcpkg, Boost.Asio/CRC, spdlog, GoogleTest/GoogleMock.

**Spec:** ../specs/2026-10-20-messages-design.md

## Global constraints

- Wire header: uint64 magic + uint32 type + uint64 payload size; trailer: uint32 CRC-32.
- Big-endian fixed-width fields; PriceDollar=float encoded as IEEE-754 binary32.
- SequenceNumber=uint64_t; strings/counts have uint32 prefixes.
- Validate sizes/counts before allocation; reject invalid/truncated/trailing data.
- Preserve class callbacks, Allman style, and current TCP framing/queue/cancellation behavior.
